# 泥土小伙伴（微信小游戏）

一款原创的“身体参与解谜”微信小游戏。角色、美术、关卡、名称与音频反馈均为原创程序实现。

## 运行

1. 打开微信开发者工具，选择「小游戏」。
2. 导入本目录 `/Users/lyf/Documents/snake`。
3. 没有 AppID 时选择测试号；发布前在 `project.config.json` 替换为自己的 AppID。

横屏游玩；每次明确滑动移动一格，动画期间最多缓冲后续两步，斜向模糊滑动会被忽略。地图页可开启底部辅助方向键。轻触不同蠕虫可切换伙伴，底部可撤销、重开或返回地图。

## 已实现

- 60 个原创灰盒关卡、12 个区域章节，每章 5 关；所有试玩关卡均有可自动回放的官方解法
- 多蠕虫控制，剪刀可把身体分成独立伙伴
- 每个身体段拥有稳定 ID、坐标、前后连接和独立状态，可查询、赋能与从任意连接点切断
- 关卡使用 `tiles / entities / objectives / links` 数据描述，组件解释机关能力，核心逻辑不包含关卡 ID 特判
- 身体导电 `+`、融合点 `M`、短门 `2`（长度不超过 2）、重门 `4`（长度至少 4）与锁存开关 `T`
- 只能按风纹方向进入的单向根门 `^ v < >`
- 成对回声花 `O` 会把整条身体保持原形传送到另一端
- 酸果 `C` 会缩短一节身体，可与苹果配合主动改变长度
- 心钥 `K` 会背在身上；经过心锁 `L` 时消耗一把，只打开当前这道锁
- 苹果增长、推石、按钮门、易碎蛋与草窝
- 标题、选关、教程提示、结算、撤销、重开与进度保存
- 首次滑动教学、伙伴切换教学、静音、分享和前后台恢复
- 程序化动画、粒子、震屏、触觉和合成音效
- 无外部依赖、无网络请求、全部 Canvas 绘制

## 发布前

- 在 `project.config.json` 中替换正式 AppID 和项目名称。
- 在微信公众平台补充 1:1 图标、分享图、隐私说明和类目资质。
- 在小程序数据分析中配置自定义事件 `game_flow`，字段为 `action / level_id / level / chapter / moves / mechanics / screen / challenge / source / target_moves`。
- 使用真机测试至少覆盖一台低端 Android 与一台 iPhone。
- 根据内部试玩数据继续调整关卡解法和难度曲线。
